### 概要
与えられた2D迷路のグリッドにおいて、スタート位置 `S` からゴール位置 `E` までの最短経路を見つけてください。

グリッドは文字列の配列で与えられます。
- `.` = 通路（移動可能）
- `#` = 壁（通行不可）
- `S` = スタート位置
- `E` = ゴール（出口）

スタートからゴールに至るまでの座標のリスト（`[row, col]` のリスト）を順番に返してください。移動できる方向は上下左右の4方向です。

*(Given a 2D grid representing a maze with a start `S` and an end `E`, find the shortest path from `S` to `E`. Return the sequence of coordinates as a list of `[row, col]` representing the path from start to end, moving in 4 cardinal directions.)*

---

### 制約
- グリッドの縦・横のサイズは $1$ 以上 $50$ 以下です。
- スタート `S` とゴール `E` は必ずそれぞれ1つずつ存在します。
- 必ず有効な経路が存在します。

---

### 挑戦課題 (Challenge)
- **目標時間計算量 (Target Time Complexity):** `O(R \cdot C)` （$R$ は行数、$C$ は列数）
- **目標空間計算量 (Target Space Complexity):** `O(R \cdot C)`

---

### 入出力例
**例 1:**
- **入力:**
  `maze`: `["S.#.", ".#.#", "...E"]`
  `S.#.`
  `.#.#`
  `...E`
- **出力:** `[[0, 0], [1, 0], [2, 0], [2, 1], [2, 2], [2, 3]]`
- **説明:** `(0, 0)` からスタートし、障害物を避けながら最短で `(2, 3)` のゴール（E）に到達する座標の順序を返します。

**例 2:**
- **入力:**
  `maze`: `["S.E", "...", "..."]`
  `S.E`
  `...`
  `...`
- **出力:** `[[0, 0], [0, 1], [0, 2]]`
- **説明:** 下回りを通る遠回りな経路も存在しますが、最もステップ数が少ない（最短の）上側の直線ルート [[0, 0], [0, 1], [0, 2]] を返します。

**例 3:**
- **入力:**
  `maze`: `["S.", ".E"]`
  `S.`
  `.E`
- **出力:** `[[0, 0], [1, 0], [1, 1]] または [[0, 0], [0, 1], [1, 1]]`
- **説明:** 同じ長さの最短経路が複数存在する場合、そのうちのいずれか1つの有効な経路を返せば正解となります。
