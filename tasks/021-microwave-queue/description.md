### 概要
お昼休みの給湯室には電子レンジが1台しかありません。複数の人たちがそれぞれ異なる到着時刻（`arrival`）と温めにかかる時間（`duration`）を持って電子レンジの前にやってきます。

電子レンジが空いたとき、**「すでに到着している人の中で、温め時間が最も短い人」**が次にレンジを使用します。
- 温め時間が同じ場合は、到着時刻が早い人を優先します。
- 到着時刻も同じ場合は、元の番号（インデックス）が小さい人を優先します。

全員が電子レンジを使い終えるまでの、利用する人の順番（インデックスのリスト）を返してください。

*(Given the arrival times and cooking durations of multiple people sharing a single microwave, simulate the Shortest Job First scheduling order. Return the chronological list of person indices as they use the microwave.)*

---

### 制約
- `1 <= arrival.length <= 1000`
- `0 <= arrival[i] <= 100000`
- `1 <= duration[i] <= 1000`

---

### 挑戦課題 (Challenge)
- **目標時間計算量 (Target Time Complexity):** `O(N log N)`
- **目標空間計算量 (Target Space Complexity):** `O(N)`

---

### 入出力例
**例 1:**
- **入力:** `arrival = [0, 2, 4]`, `duration = [5, 2, 1]`
- **出力:** `[0, 2, 1]`
- **説明:**
  - $t = 0$: 人0のみが到着しています。人0がレンジを使い始め、 $t = 5$ に終了します。
  - $t = 5$: すでに人1（到着2、時間2）と人2（到着4、時間1）が到着しています。温め時間が短い人2（時間1）が次に使います（ $t = 5 \to 6$）。
  - 最後に人1が使います。

**例 2:**
- **入力:** `arrival = [0, 1, 3]`, `duration = [3, 1, 2]`
- **出力:** `[0, 1, 2]`
- **説明:**
  - $t = 0$: 人0が到着し、使い始めます（ $t = 0 \to 3$）。
  - $t = 3$: 人1（到着1、時間1）と人2（到着3、時間2）が待っています。温め時間が短い人1が選ばれます（ $t = 3 \to 4$）。
  - 最後に人2が使います（ $t = 4 \to 6$）。

**例 3:**
- **入力:** `arrival = [0, 1, 2]`, `duration = [10, 2, 1]`
- **出力:** `[0, 2, 1]`
- **説明:**
  - $t = 0$: 人0が到着し、使い始めます（ $t = 0 \to 10$）。
  - 人0がレンジを使っている間に、人1（到着1、時間2）と人2（到着2、時間1）が到着して待ちます。
  - $t = 10$ にレンジが空いたとき、待っている人の中で温め時間が最も短い人2（時間1）が次に選ばれます（ $t = 10 \to 11$）。
  - 最後に人1が使います（ $t = 11 \to 13$）。
