### 概要
整数からなる配列 `nums` が与えられます。配列のすべての要素の和を返す関数 `array_sum(nums)` を実装してください。

*(Given an array of integers `nums`, implement the function `array_sum(nums)` that returns the sum of all elements in the array.)*

---

### 制約
- `0 &lt;= nums.length &lt;= 10⁴`
- `-10⁹ &lt;= nums[i] &lt;= 10⁹`

---

### 挑戦課題 (Challenge)
- **目標時間計算量 (Target Time Complexity):** `O(N)`
- **目標空間計算量 (Target Space Complexity):** `O(1)`

---

### 入出力例
**例 1:**
- **入力:** `nums = [1, 2, 3]`
- **出力:** `6`

**例 2:**
- **入力:** `nums = [-5, 4]`
- **出力:** `-1`

**例 3:**
- **入力:** `nums = [0, 2, 4, 6, 8, 10]`
- **出力:** `30`
