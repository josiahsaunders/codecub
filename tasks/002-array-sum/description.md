### 概要
2つの整数 `a` と `b` が与えられます。2つの数の和を返す関数 `array_sum(nums)` を実装してください。

*(Given two integers `a` and `b`, return the sum of the two numbers.)*

### 制約
- `-2 &lt;= nums.length &lt;= 10⁴`
- `-10⁹ &lt;= nums[i] &lt;= 10⁹`

### 挑戦課題 (Challenge)
- **目標時間計算量 (Target Time Complexity):** `O(N)`
- **目標空間計算量 (Target Space Complexity):** `O(1)`

### 入出力例

**例 1:**
- **入力:** `nums = [1, 2, 3]`
- **出力:** `6`

**例 2:**
- **入力:** `nums = [-5, 4]`
- **出力:** `-1`

**例 3:**
- **入力:** `nums = [0, 2, 4, 6, 8, 10]`
- **出力:** `30`
