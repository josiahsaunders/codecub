### 概要
与えられた文字列 `ip_address` が、正しい **IPv4 アドレス** の形式を満たしているかを判定する関数を実装してください。

*(Given a string `ip_address`, implement a function to determine if it is a valid **IPv4 address** format.)*

---

### 正しい IPv4 アドレスの条件
1. ドット (`.`) で区切られた **4 つの部分** (オクテット) で構成されていること。
2. 各部分は **0 から 255 までの整数** であること。
3. 数字以外の文字が含まれていないこと (例: アルファベットや記号)。
4. 2桁以上の数字の場合、先頭に余計な `0` (Leading Zeros) が含まれていないこと (例: `"192.168.01.1"` は不可、ただし `"0"` 単体は許可)。

---

### 制約
- `1 <= len(ip_address) <= 50`
- 入力文字列には英数字および `.` が含まれる場合があります。

---

### 挑戦課題 (Challenge)
- **目標時間計算量 (Target Time Complexity):** `O(N)` （$N$ は文字列の長さ）
- **目標空間計算量 (Target Space Complexity):** `O(N)`

---

### 入出力例
**例 1:**
- **入力:** `ip_address = "192.168.1.1"`
- **出力:** `True`
- **説明:** 4つのオクテットすべてが 0〜255 の範囲内にあり、正しい形式です。

**例 2:**
- **入力:** `ip_address = "256.100.0.1"`
- **出力:** `False`
- **説明:** 最初の部分 `256` が 255 を超えているため無効です。

**例 3:**
- **入力:** `ip_address = "192.168.01.1"`
- **出力:** `False`
- **説明:** `01` のように先頭に余計な `0` が含まれているため無効です。
