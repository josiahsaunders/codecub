### 概要
2Dゲーム開発でよく使用される「軸平行境界ボックス（Axis-Aligned Bounding Box, AABB）」による矩形同士の衝突判定を実装してください。2つの矩形 `box1` と `box2` の座標が与えられたとき、それらが重なり合っている（衝突している）場合は `True`、そうでない場合は `False` を返してください。

*(Given two axis-aligned 2D bounding boxes, implement a function to determine if they intersect (overlap). Return `True` if they collide, and `False` otherwise.)*

---

### 定義・入力形式
各ボックスは `[x, y, width, height]` の4つの整数要素を持つリストまたはタプルで表現されます：
- `x`: 左上（または左下）のX座標
- `y`: 左上（または左下）のY座標
- `width`: ボックスの幅（正の整数）
- `height`: ボックスの高さ（正の整数）

※ 本課題では、座標系は一般的な2Dスクリーン座標（X軸は右向き、Y軸は下向き）を想定し、ボックスの辺同士が完全に接している（重なりが面積0）状態は「衝突している」とみなします。

---

### 制約
- 座標および寸法は整数値で与えられます。
- `-10⁹ <= x, y <= 10⁹`
- `1 <= width, height <= 10⁹`

---

### 挑戦課題 (Challenge)
- **目標時間計算量 (Target Time Complexity):** `O(1)` （定数回の条件比較のみ）
- **目標空間計算量 (Target Space Complexity):** `O(1)`

---

### 入出力例
**例 1:**
- **入力:** `box1 = [0, 0, 5, 5]`, `box2 = [3, 3, 5, 5]`
- **出力:** `True`
- **説明:** 2つの矩形は座標 `(3, 3)` から `(5, 5)` の領域で重なり合っています。

**例 2:**
- **入力:** `box1 = [0, 0, 2, 2]`, `box2 = [3, 3, 2, 2]`
- **出力:** `False`
- **説明:** 2つの矩形は離れており、重なりはありません。

**例 3:**
- **入力:** `box1 = [0, 0, 4, 4]`, `box2 = [4, 0, 4, 4]`
- **出力:** `True`
- **説明:** 境界線（X = 4）で完全に接しているため、衝突と判定します。
