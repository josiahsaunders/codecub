### 概要
2つの整数 `a` と `b` が与えられます。2つの数の和を返す関数 `add_two_numbers(a, b)` を実装してください。

*(Given two integers `a` and `b`, return the sum of the two numbers.)*

### 制約
- `-10⁹ &lt; a, b &lt; 10⁹`

### 入出力例

**例 1:**
- **入力:** `a = 3`, `b = 5`
- **出力:** `8`

**例 2:**
- **入力:** `a = -10`, `b = 4`
- **出力:** `-6`

**例 3:**
- **入力:** `a = -6`, `b = -9`
- **出力:** `-15`
