### 概要
ローマ数字で表された文字列 `s` を受け取り、それを変換した整数を返す関数 `romanToInt(s)` を実装してください。

*(Given a roman numeral string `s`, convert it to an integer and return the result.)*

---

### 仕様
ローマ数字は以下の7つの文字で構成されています。

| 記号 (Symbol) | 値 (Value) |
| :---: | :---: |
| `I` | 1 |
| `V` | 5 |
| `X` | 10 |
| `L` | 50 |
| `C` | 100 |
| `D` | 500 |
| `M` | 1000 |

通常、ローマ数字は大きい値から小さい値へと左から右に記述されます。ただし、引き算を表す場合は例外があり、例えば `IV` (4) や `IX` (9) のように、小さな値が大きな値の左側に置かれるときは、その値を引いたものとして計算します。

---

### 制約
- `1 <= s.length <= 15`
- `s` は文字 `('I', 'V', 'X', 'L', 'C', 'D', 'M')` のみで構成されています。
- 与えられた文字列は常に `[1, 3999]` の範囲の有効なローマ数字です。

---

### 挑戦課題 (Challenge)
- **目標時間計算量 (Target Time Complexity):** `O(N)` （$N$ は文字列の長さ）
- **目標空間計算量 (Target Space Complexity):** `O(1)` （マッピング用テーブルのサイズは固定のため）

---

### 入出力例
**例 1:**
- **入力:** `s = "III"`
- **出力:** `3`
- **説明:** `3` は `3` つの `I` で表されます。

**例 2:**
- **入力:** `s = "LVIII"`
- **出力:** `58`
- **説明:** `L = 50`, `V = 5`, `III = 3` なので `50 + 5 + 3 = 58` となります。

**例 3:**
- **入力:** `s = "MCMXCIV"`
- **出力:** `1994`
- **説明:** `M = 1000`, `CM = 900`, `XC = 90`, `IV = 4` となります。
