### 概要
与えられた整数の配列 `nums` の中で、最も大きい値（最大値）を返してください。

*(Given an array of integers `nums`, return the largest value (maximum) in the array.)*

---

### 制約
- `1 <= nums.length <= 10⁵`
- `-10⁹ <= nums[i] <= 10⁹`
- 配列には少なくとも1つの要素が含まれます。

---

### 挑戦課題 (Challenge)
- **目標時間計算量 (Target Time Complexity):** `O(N)`
- **目標空間計算量 (Target Space Complexity):** `O(1)`

---

### 入出力例
**例 1:**
- **入力:** `nums = [5, 3, 8, 1, 4]`
- **出力:** `8`
- **説明:** 配列の中で最も大きい数は `8` です。

**例 2:**
- **入力:** `nums = [-2, 0, -10, -8, -5]`
- **出力:** `0`
- **説明:** 配列の中で最も大きい数は `0` です。

**例 3:**
- **入力:** `nums = [7]`
- **出力:** `7`
- **説明:** 要素が1つだけの場合、その要素自身が最大値となります。
