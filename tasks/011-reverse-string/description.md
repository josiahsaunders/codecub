### 概要
与えられた文字列 `s` を反転させた文字列を返す関数 `reverseString(s)` を実装してください。

*(Given a string `s`, return the string reversed.)*

---

### 制約
- `0 <= len(s) <= 10⁵`
- 文字列には英数字、記号、スペースが含まれる場合があります。

---

### 挑戦課題 (Challenge)
- **目標時間計算量 (Target Time Complexity):** `O(N)` （$N$ は文字列の長さ）
- **目標空間計算量 (Target Space Complexity):** `O(N)`

---

### 入出力例
**例 1:**
- **入力:** `s = "hello"`
- **出力:** `"olleh"`

**例 2:**
- **入力:** `s = "Python"`
- **出力:** `"nohtyP"`

**例 3:**
- **入力:** `s = "12345"`
- **出力:** `"54321"`
